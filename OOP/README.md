# 面向对象程序设计 (OOP) 学习仓库

本仓库包含了面向对象程序设计课程的完整C++学习代码，从C++基础语法到高级面向对象特性的全面实践。

## 💻 技术环境

- **编码格式**: GB2312
- **开发环境**: Visual Studio
- **编程语言**: C++

## 📚 核心内容

### 🔤 C++基础语法
- **基本数据类型与操作符**: 变量声明、运算符重载、表达式计算
- **控制结构**: 分支语句 (if-else, switch)、循环结构 (for, while, do-while)
- **函数特性**: 内联函数、默认参数、函数重载、递归调用
- **引用与指针**: 引用概念、指针操作、函数指针使用

### 🏗️ 面向对象核心概念
- **类与对象**: 类的定义、对象创建、成员访问控制
- **构造与析构**: 构造函数、析构函数、复制构造函数
- **静态成员**: 静态数据成员、静态成员函数
- **友元函数**: 友元的使用和应用场景

### 🔄 面向对象高级特性
- **继承机制**: 单一继承、多继承、虚基类
- **多态性**: 虚函数、虚析构函数、动态绑定
- **运算符重载**: 成员函数重载、非成员函数重载、流运算符
- **模板编程**: 函数模板、类模板

### 📁 内存管理
- **动态内存分配**: new/delete操作、动态对象创建
- **对象生命周期**: 静态/动态生存期、作用域管理
- **内存安全**: malloc/free与new/delete的区别

### 🎯 实践项目
- **Point类系列**: 坐标点的完整面向对象实现
- **魔兽世界项目**: 大型综合性OOP项目实践
- **数据结构实现**: List、队列等容器的OOP实现
- **算法应用**: 排序、查找等算法的面向对象封装

## 📖 学习路径

### 第一阶段：C++基础 (1-2周)
- Hello World程序和基本语法
- 数据类型、变量和常量
- 控制结构和函数基础

### 第二阶段：面向对象入门 (3-4周)
- 类和对象的概念
- 构造函数和析构函数
- 成员函数和访问控制

### 第三阶段：高级特性 (5-8周)
- 继承和派生
- 虚函数和多态
- 运算符重载
- 模板基础

### 第四阶段：综合应用 (9-12周)
- 复杂项目开发
- STL容器使用
- 设计模式应用

### 第五阶段：深入实践 (13-17周)
- 高级模板编程
- 异常处理
- 综合项目实战
