# 微机原理与单片机汇编代码集合
> - UTF-8

本仓库包含了微机原理与单片机课程的汇编语言实验代码和练习程序，涵盖了8086/8088微处理器和51单片机的汇编编程实例。

## 📚 课程内容

这些代码涵盖了微机原理与单片机课程的核心内容：

### 🔧 基础指令实验
- **数据传输指令**: `MOV.asm`, `LEA.ASM`, `LDS.ASM`, `XCHG1.ASM`
- **算术运算指令**: `ADD.ASM`, `SUB.ASM`, `MUL.ASM`, `NEG.ASM`, `CBW.ASM`
- **逻辑运算指令**: `SHR.ASM`
- **字符串操作指令**: `MOVSB.ASM`, `CMPSB.ASM`
- **堆栈操作**: `PUSH1.ASM`, `PUSH2.ASM`

### 🔄 程序控制结构
- **循环指令**: `LOOP.ASM`, `LOOPZ.ASM`, `LOOPNZ.ASM`, `LOOPNZ2.ASM`
- **中断处理**: `INT.asm`, `INT2STRING.ASM`
- **算法实现**: `Bubble_Sort.ASM` (冒泡排序), `feibo.asm` (斐波那契数列)

### 🛠️ 接口与外设实验
- **8255A并行接口**:
  - `实验四 8255A 并行口实验（一）.asm`
  - `实验五　8255A并行口实验(二).asm`
- **8251串行通信**: `8251.asm`
- **DA转换实验**: `实验二　DA转换实验（一）.asm`
- **AD转换**: `AD.asm`

### 💡 单片机应用实例
- **LED控制**: `LED.ASM`, `P1亮灯.asm`, `P1转弯灯.ASM`
- **LCD显示**: `LCD.asm`
- **定时器应用**: `timer.asm`
- **电子琴实验**: `实验十四 电子琴实验.asm`

### 🎯 综合应用
- **多位加法运算**: `多位加法.asm`
- **表格查找**: `XLAT.asm`
- **数据定义**: `DB.ASM`, `DW.ASM`
- **Hello World程序**: `HELLO WORLD.asm`

### 环境要求
- 8086/8088汇编开发环境 (如 MASM, TASM)
- 51单片机开发环境 (如 Keil)

## 📝 注意事项

- 部分文件可能需要特定的硬件环境或仿真器支持
- 建议结合课程教材和实验指导书学习
- 代码中的地址和端口可能需要根据具体硬件平台调整
