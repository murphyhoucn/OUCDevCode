# C语言程序设计学习仓库

本仓库包含了C语言程序设计相关课程的完整学习代码，涵盖了从基础语法到高级数据结构的全面内容。

## 📚 课程模块

### 🔤 C-Programming-Design (C程序设计)
包含C语言基础编程的所有核心内容，是C语言学习的基础模块。

**技术环境**:
- 编码格式: GB2312
- 开发环境: Visual Studio

**主要内容**:
- 基础语法和数据类型
- 控制结构 (分支、循环)
- 函数定义与调用
- 数组和指针操作
- 字符串处理
- 结构体和联合体
- 文件操作
- 算法实现 (排序、查找等)

### 📊 Data-Structure-Code (数据结构)
数据结构课程的核心代码实现，包含各种经典数据结构的代码示例。

**技术环境**:
- 编码格式: GB2312
- 开发环境: Visual Studio

**主要内容**:
- 线性表的实现
- 栈和队列
- 树和二叉树
- 图结构
- 查找和排序算法
- 各章节对应的示例代码

### 🧪 Data-Structure-Exp (数据结构实验)
数据结构课程的实验代码，通过实际编程加深对数据结构概念的理解。

**技术环境**:
- 编码格式: GB2312
- 开发环境: Visual Studio

**主要内容**:
- 循环队列的设计与实现
- 链栈的设计与实现
- 二叉树遍历算法
- 哈夫曼树构建
- 拓扑排序实现
- 八皇后问题求解
- 汉诺塔递归算法

### 🚀 High-level-Language-Programming (高级语言程序设计)
高级语言程序设计课程代码，使用现代化的开发环境和编程实践。

**技术环境**:
- 编码格式: UTF-8
- 开发环境: VSCode
- 运行平台: Linux Server

**主要内容**:
- OJ (Online Judge) 编程题目
- 学习测试代码
- 现代C语言编程实践

## 🛠️ 技术特点

- **多环境支持**: 从经典的Visual Studio到现代的VSCode开发环境
- **编码兼容**: 同时支持GB2312和UTF-8编码格式
- **跨平台**: 支持Windows和Linux开发环境
- **完整体系**: 从基础语法到高级数据结构的完整学习路径

## 📖 学习建议

1. **基础入门**: 从 `C-Programming-Design` 开始，掌握C语言基础语法
2. **算法强化**: 通过 `Data-Structure-Code` 学习经典数据结构
3. **实践提升**: 利用 `Data-Structure-Exp` 进行实验编程
4. **进阶应用**: 通过 `High-level-Language-Programming` 提升编程技能

## ⚠️ 使用说明

- **编码格式**: 注意不同模块使用的字符编码格式
- **开发环境**: 根据项目需求选择合适的IDE
- **编译环境**: 确保编译器支持相应的C语言标准
- **文件组织**: 代码按课程章节和实验要求进行组织
