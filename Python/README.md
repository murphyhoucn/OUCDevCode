# Python 程序设计学习仓库

本仓库包含了Python程序设计课程的完整学习代码，从Python基础语法到高级应用的全面实践，涵盖了数据处理、面向对象编程、文件操作、数据可视化等多个领域。

## 🐍 技术环境

- **编程语言**: Python 3.x
- **开发工具**: PyCharm & Python IDLE
- **编码格式**: UTF-8
- **主要库**: matplotlib, numpy, wordcloud, json等

## 📚 学习内容

### 🔤 Python基础语法
- **基本概念**: 变量、数据类型、运算符、转义字符
- **控制结构**: if语句、while循环、for循环、break/continue
- **数据结构**: 列表、元组、字典、集合的操作和应用
- **函数编程**: 函数定义、参数传递、返回值、模块化编程

### 📁 文件与数据处理
- **文件操作**: 读取文件、写入文件、文件异常处理
- **JSON数据**: JSON读写、数据序列化和反序列化
- **文本处理**: 字符串操作、文本分析、词频统计
- **数据存储**: 数据持久化存储和读取

### 🎯 面向对象编程
- **类与对象**: 类的定义、实例化、属性和方法
- **继承与多态**: 子类设计、方法重写、属性继承
- **特殊方法**: `__init__`方法、魔法方法的使用
- **实例应用**: Dog类、汽车类、餐馆类等实际案例

### 📊 数据分析与可视化
- **数学计算**: 数值计算、统计分析、数学函数应用
- **图形绘制**: matplotlib绘图、图表制作
- **数据可视化**: 词云生成、雷达图、几何图形绘制
- **科学计算**: numpy数组操作、数据分析

### 🧮 算法与应用
- **数学算法**: 斐波那契数列、阶乘计算、素数判断
- **排序搜索**: 各种排序算法、数据查找
- **递推算法**: 动态规划、递归应用
- **实用工具**: 进制转换、日期时间处理、文本进度条

### 🌐 实际应用项目
- **个人工具**: BMI计算器、个人所得税计算、温度转换
- **文本分析**: 英文分词、词频统计、文本格式化
- **数据处理**: 学生成绩管理、IP地址验证、身份证检验
- **图形应用**: 几何图形绘制、艺术图案生成

## 🎯 学习建议

### 第一阶段：Python基础
1. 从Hello World开始，掌握基本语法
2. 学习变量、数据类型和运算符
3. 掌握控制结构和循环

### 第二阶段：数据结构
1. 深入学习列表、字典、元组
2. 掌握数据的操作和处理方法
3. 练习复杂数据结构的应用

### 第三阶段：函数与模块
1. 学习函数定义和调用
2. 掌握参数传递和返回值
3. 理解模块化编程思想

### 第四阶段：面向对象
1. 学习类和对象的概念
2. 掌握继承和多态
3. 应用OOP解决实际问题

### 第五阶段：高级应用
1. 文件操作和异常处理
2. 数据分析和可视化
3. 综合项目实践
