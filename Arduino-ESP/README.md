# ESP和Arduino开发项目集合

本仓库包含了基于ESP系列芯片和Arduino平台的嵌入式开发项目代码，涵盖了物联网、传感器控制、图像处理等多个应用领域。

## 🔧 平台支持

### Arduino Uno
经典的Arduino开发板项目，包含基础的传感器和执行器控制实例。

### ESP8266
基于ESP8266 WiFi芯片的物联网项目，支持无线连接和Web服务器功能。

### ESP32系列
- **ESP32S**: ESP32标准版本的开发项目
- **ESP32CAM**: 集成摄像头的ESP32开发项目，包含图像采集、流媒体传输等功能

## 📦 项目结构

- **Arduino_Uno/**: Arduino Uno开发板相关项目
- **ESP8266/**: 基于ESP8266的WiFi物联网项目
- **ESP32S/**: ESP32标准版开发项目
- **ESP32CAM/**: ESP32-CAM摄像头模块项目
- **Keyboard/**: 键盘相关的输入设备项目
- **libraries/**: 项目依赖的库文件
- **blinker-library-master/**: Blinker物联网平台开发库

## 🌟 主要特性

- **多平台支持**: 涵盖Arduino和ESP系列主流开发平台
- **物联网应用**: 包含WiFi连接、Web服务器、远程控制等功能
- **传感器集成**: 支持多种传感器的数据采集和处理
- **图像处理**: ESP32CAM项目支持实时图像采集和网络传输
- **完整示例**: 从基础的LED控制到复杂的网络应用
